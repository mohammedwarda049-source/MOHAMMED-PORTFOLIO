ARCH MOHAMMED WARDA — GitHub Pages Ready

هذه النسخة مهيأة للنشر على GitHub Pages.

الرفع:
1) أنشئ Repository جديداً على GitHub.
2) فك ضغط ملف ZIP على جهازك.
3) ارفع محتويات المجلد مباشرة إلى جذر المستودع بحيث يكون index.html في المستوى الرئيسي.
4) من Settings > Pages اختر Deploy from a branch.
5) اختر main و / (root) ثم Save.

مهم: لا ترفع ملف ZIP نفسه داخل المستودع وتتوقع أن يفك GitHub ضغطه تلقائياً.
